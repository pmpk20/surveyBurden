# One-sentence summary of a burden object

One-sentence summary of a burden object

## Usage

``` r
summary_line(x, ...)
```

## Arguments

- x:

  A
  [`burden_report()`](https://pmpk20.github.io/surveyBurden/reference/burden_report.md)
  object.

- ...:

  Unused.

## Value

A single character string.
