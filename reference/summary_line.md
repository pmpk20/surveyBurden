# One-sentence summary of a burden object

One-sentence summary of a burden object

## Usage

``` r
summary_line(x, ...)
```

## Arguments

- x:

  A
  [`respondent_burden()`](https://pmpk20.github.io/surveyBurden/reference/respondent_burden.md)
  table (the no-routes form).

- ...:

  Unused.

## Value

A single character string.
